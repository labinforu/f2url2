# F2URL 2 — 0.2.7 RC1 Compact

**Статус: опубликованная предварительная версия (Pre-release).**

Платформа: Windows 10/11 x64. Бесплатное настольное ПО; собственный исходный код не распространяется.

Установщик: `F2URL-0.2.7-rc1-Compact-Setup.exe`. Размер: **156,6 МиБ**. SHA-256: `b4c96c706d26315e127ae44025d5df82f7995708c4406ebde53a9d31731e2466`. Хеш подтверждён GitHub для загруженного файла.

## Возможности

- Поиск номеров записей о поверке в Word и Excel.
- Создание гиперссылок с сохранением исходных документов.
- Несколько ссылок из одной ячейки Excel — на отдельном листе.
- Ручная нумерация и сортировка списка, в том числе `1.1`, `1.2`.
- Пакетное сохранение публичных карточек Аршина в PDF, отмена и повтор ошибок.
- Встроенная справка и лицензионные документы.

## Обновления GitHub

- Фоновая проверка и ручная проверка в разделе «О программе».

## Установка и ярлыки

В мастере установки можно самостоятельно выбрать каталог. В меню «Пуск» создаётся группа **Lab-Info → F2URL 2** с запуском программы, документацией, лицензиями и удалением. Штатное удаление также доступно в параметрах Windows.

## Особенности Compact

Неиспользуемые Qt WebEngine, Qt PDF и другие компоненты исключены из сборки. Chromium Headless остаётся внутри установщика: пользователю не нужно устанавливать Python или браузер.

## Ограничения

Работа с Аршином зависит от доступности сети и реестра. PDF — информационная копия публичной страницы. Программа не проверяет действительность поверок и не ведёт реестр оборудования. Проверяйте результат, особенно оформление утверждённых форм.
