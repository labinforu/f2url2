# Безопасность и конфиденциальность

F2URL — локальное настольное приложение. Для обработки списков Word и Excel не требуется регистрация на сайте Lab-Info. При скачивании PDF приложение обращается к публичным страницам ФГИС «Аршин» через встроенный Chromium.

## Сообщить о проблеме безопасности

Не размещайте сведения об уязвимостях, секреты, конфиденциальные файлы или информацию, позволяющую нанести вред, в открытых GitHub Issues. Свяжитесь с разработчиком по адресу aas@lab-info.ru либо через https://lab-info.ru/contacts/.

Для обычных ошибок приложите только обезличенный пример: без настоящих форм 2, заводских номеров оборудования, персональных данных и коммерческой информации.

## Установщик и контрольная сумма

Скачивайте программу только из официальных источников и проверяйте SHA-256 файла. Наличие установщика на GitHub само по себе не означает, что EXE подписан сертификатом издателя.

F2URL не является официальным продуктом ФГИС «Аршин» и не заменяет проверку записей в официальном реестре.
