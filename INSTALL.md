# Установка F2URL 2 (Windows)

Программа предназначена для Windows 10/11 x64. Для конечного пользователя не требуется отдельно устанавливать Python, Qt или Chromium.

## Скачивание и проверка файла

1. После публичного выпуска перейдите в [Releases](https://github.com/labinforu/f2url2/releases).
2. Скачайте файл `F2URL-0.2.6-rc1-Compact-Setup.exe` и соответствующий файл контрольной суммы `.sha256`.
3. Откройте PowerShell в папке со скачанным Setup и выполните:

```powershell
Get-FileHash -Path ".\F2URL-0.2.6-rc1-Compact-Setup.exe" -Algorithm SHA256
```

Для новой сборки 0.2.6 RC1 по журналу разработчика указан SHA-256 (проверить повторно по самому файлу перед публикацией):

```text
07354a81210d2c64e761d36ca5a0eab75b2766234be541cb2868e8f316d40b9d
```

**Перед выпуском контрольная сумма загруженного установщика должна быть подтверждена повторно.** Если SHA-256 отличается от опубликованного, не запускайте файл.

Не отключайте SmartScreen или антивирус ради установки; при предупреждении сначала проверьте источник и целостность файла.

## Установка и начало работы

1. Запустите скачанный Setup.
2. Прочитайте пользовательское лицензионное соглашение; если принимаете его условия, продолжите установку.
3. Откройте F2URL 2 через меню «Пуск» или ярлык.
4. Нажмите F1, чтобы открыть встроенную справку.
5. Импортируйте Word (`.docx`) или Excel (`.xlsx`) либо вставьте номера вручную.
6. Проверьте нумерацию и названия оборудования, затем выберите создание ссылок или скачивание PDF.
7. Откройте выходные документы и проверьте оформление и правильность каждой записи.

Когда в одной ячейке Excel несколько свидетельств, программа создаёт на дополнительном листе по одной ссылке для каждого номера.

## Если возникла ошибка

Проверьте подключение к интернету и доступность ФГИС «Аршин». При ошибке импорта проверьте формат и содержимое документа. Для сообщения об ошибке используйте [GitHub Issues](https://github.com/labinforu/f2url2/issues/new/choose) или [контакты Lab-Info](https://lab-info.ru/contacts/).

Не прикладывайте необезличенные документы лабораторий и персональные данные. Полученные PDF являются информационными копиями страниц, а не подписанными свидетельствами.
